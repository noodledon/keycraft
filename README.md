# keycraft

A fixed way to decide a keymap for any app. Find the work someone repeats, pick one mechanism for it (a letter, a chord, or a jump menu), then bind a familiar key. The agent instructions are [SKILL.md](SKILL.md).

## Install

Grok:

```sh
git clone https://github.com/noodledon/keycraft.git ~/Projects/keycraft
ln -s ~/Projects/keycraft ~/.grok/skills/keycraft
```

Then `/keycraft`, or ask for vim-style shortcuts, a Fizzy-style keyboard, a jump menu, or Cmd and Ctrl shortcuts.

The Fizzy mapping is [references/fizzy.md](references/fizzy.md), from the [37signals shortcut guide](https://help.fizzy.do/3/fizzy-help-guide/69/keyboard-shortcuts). Web host notes are [references/web.md](references/web.md).
