# keycraft

A keymap a person can use before they memorize it. One door key opens a jump menu. Each screen has a few single-letter verbs. Arrows walk, then a verb acts on the selection. Esc closes one layer. `?` shows a one-line cheat.

The agent instructions are [SKILL.md](SKILL.md). Terms live there.

## Install

Grok:

```sh
git clone https://github.com/noodledon/keycraft.git ~/Projects/keycraft
ln -s ~/Projects/keycraft ~/.grok/skills/keycraft
```

Then `/keycraft`, or ask for vim-style shortcuts, a Fizzy-style keyboard, or a jump menu.

The Fizzy mapping is [references/fizzy.md](references/fizzy.md), from the [37signals shortcut guide](https://help.fizzy.do/3/fizzy-help-guide/69/keyboard-shortcuts). Web host notes are [references/web.md](references/web.md).
