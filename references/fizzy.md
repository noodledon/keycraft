# Fizzy, mapped onto keycraft

Read this when the app is a board of cards, or the user names Fizzy. Source: [Keyboard Shortcuts](https://help.fizzy.do/3/fizzy-help-guide/69/keyboard-shortcuts) and [The Fizzy Menu](https://help.fizzy.do/3/fizzy-help-guide/42/the-fizzy-menu) (37signals).

Fizzy's published menu is a list of places (assigned cards, boards, tags, people, accounts), opened from every page with `J`. Search is a separate key, `K`. The help guide does not describe type-to-filter inside that menu. The jump menu's filter and land behavior is the keycraft door, so a long list of names stays fast.

Start a board app from the tables below. Keep a letter on its Fizzy key when that key is free. Move it when a gate or an existing chord owns it. The board cheat and the card cheat name different verbs.

## Every screen

| Fizzy action | Key | Term |
| --- | --- | --- |
| Fizzy menu | `J` (Fizzy also binds Cmd/Ctrl+`J`) | Door. Add the letter. Leave the chord alone. |
| Search | `K` | Search |
| Home / Assigned to me / Added by me | `1` `2` `3` | Areas |
| Pin | `P` | Verb, when the app has pins |
| Notification settings | `N` | Verb, when the app has that screen |
| Add a board | `B` | Create, for the board noun |
| Focus filter | `F` | Focus filter |
| Go back | `←` | Back, when there is history |
| Close dialog / cancel / go back | Esc | Back one layer |

## Board

The help text says: move between cards using the arrow keys first. That is two-beat.

| Fizzy action | Key | Term |
| --- | --- | --- |
| Move between columns | `←` `→` | Walk |
| Move between cards | `↑` `↓` | Walk. Add `j` `k` on a vertical list. |
| Open card | Enter | Open |
| Add a card | `C` | Create |
| Move to Not Now | `[` | Defer |
| Mark as Done | `]` | Done |
| Assign to me | `M` | Assign to me |

## Card

These verbs exist only while a card is open. `M` assigns on both screens. Done is `]` on the board and `D` on the card, because `]` is neighbor-shaped on a board and free on a card.

| Fizzy action | Key | Term |
| --- | --- | --- |
| Edit a card | `E` | Edit |
| Choose assignees | `A` | Verb for the assignee list |
| Assign to me | `M` | Assign to me |
| Mark as Done | `D` | Done |
| Tag a card | `T` | Tag |
| Pin or unpin | Shift+`P` | Chord. Leave it. |
| Watch or stop watching | Shift+`N` | Chord. Leave it. |
| Golden ticket | Shift+`G` | Chord. Skip unless the app has this noun. |
| Save / save and create another | Cmd/Ctrl+Enter, Cmd/Ctrl+Shift+Enter | Chords. Leave them. |
